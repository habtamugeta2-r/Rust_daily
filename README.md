# Hello Rust: Rust Programming Learning Journey for Beginners

A beginner-friendly Rust project created as part of my Rust learning journey. This repository focuses on learning the core concepts of the Rust programming language through small, practical examples and a simple project structure.

This project is designed for developers who want to learn Rust from scratch, understand Rust syntax, and explore key concepts like variables, mutability, and basic output in a hands-on way.

The project is intentionally simple, making it easy for beginners to read, understand, and build on. It demonstrates a minimal Rust program and serves as a starting point for deeper learning in areas such as:

- ownership and borrowing

## Prerequisites

Before running this project, make sure you have Rust installed.

Install Rust using:

```bash
curl --proto '=https' --tlsv1.2 https://sh.rustup.rs -sSf | sh
```

Then verify installation:

```bash
rustc --version
cargo --version
```

## Run the project

From the project root, run:

```bash
cargo run
```
